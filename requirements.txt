# FoodSupply_Test Project Requirements

This project contains two main parts: a Go Backend and a Flutter Frontend. Below is the comprehensive list of system requirements, dependencies, and their exact versions required to run the application.

## 1. System & Infrastructure Requirements
The following software is required on the host system to run the backend services via Docker.

- **Docker Engine**: Required to run containerized services.
- **Docker Compose**: Orchestrates the database and caching containers.
- **PostgreSQL**: Version `16` (Image: `postgres:16-alpine`)
  - Port mapping: `5433` (host) to `5432` (container)
- **Redis**: Version `7` (Image: `redis:7-alpine`)
  - Port mapping: `6379` (host) to `6379` (container)

## 2. Backend Requirements (Go Application)
Located in the `backend/` directory.

### Core Language
- **Go SDK**: `1.23`

### Exact Dependencies

- `github.com/go-chi/chi/v5` `v5.1.0`
